# INJIVA Pandas Sales Intelligence

## Project Overview

An advanced retail sales intelligence and data engineering project developed for INJIVA Digital Systems using the fictional ZimTech Retail Holdings dataset.

The project transforms raw sales records into validated financial and business intelligence reports.

**Developer:** Tinashe Mutanda

**Assessment reference:** INJIVA-DS-DA-PANDAS-001

## Technologies

- Python 3
- Pandas
- NumPy
- Jupyter Notebook
- pytest

## Installation

Clone the repository:

```bash
git clone https://github.com/Tinashemutanda/injiva-pandas-sales-intelligence.git
cd injiva-pandas-sales-intelligence
```

Install dependencies:

```bash
python -m pip install -r requirements.txt
```

## Running the Pipeline

```bash
python -m src.pipeline
```

The pipeline validates, cleans, transforms and analyses the original sales dataset before exporting CSV reports.

## Running Automated Tests

```bash
python -m pytest tests/ -v
```

Tests cover data quality, financial calculations, merge integrity, invalid transactions and pipeline execution.

## Jupyter Notebook

```bash
jupyter notebook
```

Open `notebooks/sales_analysis.ipynb` and execute all cells in order.

## Limitations

The project uses a small fictional dataset covering January 2026. Missing records and rejected transactions limit the reliability of long term business forecasts.

No data visualisation libraries are used, in accordance with the assessment requirements.
